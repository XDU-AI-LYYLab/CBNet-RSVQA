# CBNet-RSVQA

A PyTorch implementation for "Remote Sensing Visual Question Answering (RSVQA)" on the RSVQA-LR, RSVQA-HRv1 and RSVQA-HRv2 datasets.

The model combines remote-sensing image features extracted by "ResNet-152" with question representations generated by"RoBERT". Attention modules are used for multimodal feature interaction and answer classification.

Features

- Supports RSVQA-LR and RSVQA-HR datasets
- ResNet-152 visual encoder
- RoBERTa question encoder
- Multi-scale visual feature extraction
- Channel and spatial attention
- Text-guided cross-attention
- AutoAugment-based image augmentation
- Question-only baseline for language-bias analysis
- Evaluation using OA, AA and question-type accuracy

Dataset Preparation

Download the official RSVQA-LR or RSVQA-HR dataset separately. The datasets and model checkpoints are not included in this repository.

Organize RSVQA-LR as follows:

```text
RSVQA_LR/
├── Images_LR/
├── all_questions.json
├── all_answers.json
├── LR_split_train_images0.json
├── LR_split_val_images.json
├── LR_split_val_questions.json
├── LR_split_val_answers.json
├── LR_split_test_images0.json
├── LR_split_test_questions.json
└── LR_split_test_answers.json
```

Organize RSVQA-HR as follows:

```text
RSVQA_HR/
├── Images_HR/
├── USGS_split_train_images.json
├── USGS_split_train_questions.json
├── USGS_split_train_answers.json
├── USGS_split_val_images.json
├── USGS_split_val_questions.json
├── USGS_split_val_answers.json
├── USGS_split_test_images.json
├── USGS_split_test_questions.json
└── USGS_split_test_answers.json
```

The dataset loader automatically:

- Reads TIFF remote-sensing images
- Tokenizes questions using RoBERTa
- Builds the answer vocabulary from the training split
- Groups numerical answers into intervals
- Applies image augmentation during training

RSVQA-LR uses 9 answer classes, while RSVQA-HR uses 94 answer classes.

Pretrained Models

The code uses RoBERTa-base and ImageNet-pretrained ResNet-152 weights. Place them in:

```text
offline_models/
├── roberta-base/
├── resnet-152-processor/
└── resnet152-imagenet1k-v1.pth
```

Alternatively, modify the `from_pretrained()` and ResNet weight paths in the source code to download the models from Hugging Face and torchvision.

Training

Check the dataset type, data path, GPU configuration and hyperparameters in `train.py`, then run:

```bash
python train.py
```

The main default settings used by the experiments include:

```text
Sequence length: 40
Learning rate:   1e-5
Optimizer:       AdamW
Precision:       Mixed precision
Random seed:     42
```

Model checkpoints are saved according to validation performance.

Question-Only Baseline

The question-only model excludes image features and can be used to measure language bias in the dataset:

```bash
python train_only_question.py
```

Evaluation

Set the checkpoint path and dataset configuration in `test.py`:

```python
CKPT_PATH = "path/to/model.ckpt"
```

Then run:

```bash
python test.py
```

The evaluation script reports:

- Overall Accuracy (OA)
- Average Accuracy (AA)
- Area or rural/urban accuracy
- Presence accuracy
- Count accuracy
- Comparison accuracy

Some test configurations also save incorrectly predicted samples as a JSON file for further error analysis.

Model Overview

The multimodal model contains:

1. A ResNet-152 image encoder for multi-scale visual features
2. CBAM modules for channel and spatial attention
3. A RoBERTa encoder for question representations
4. Convolutional and recurrent text feature extraction
5. Image self-attention and text self-attention
6. Text-guided cross-attention
7. A multimodal fusion and answer-classification module

Notes

- Update dataset and pretrained-model paths before training.
- Configure your own CUDA device through `CUDA_VISIBLE_DEVICES`.
- Do not commit API keys, dataset files or model checkpoints.
- Training RSVQA-HR requires significantly more GPU memory than RSVQA-LR.
- Validation and test answer mappings must be created from the training split.
